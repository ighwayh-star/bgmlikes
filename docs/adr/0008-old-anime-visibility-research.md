# ADR 0008：研究记录——推荐列表"缺少老动画"的归因（结论：非系统 bug，不改）

日期：2026-08-13

> **更新（2026-08-18）**：本 ADR 的归因结论仍有效，但"不改"已被推翻——见 [ADR 0009](0009-old-anime-tag-boost.md)（标签打分层 Route A，β=0.5 全用户，已上线）。原"后续可选方案"的配额/池子重排两条算法外路线未采用。

## 背景

用户观察：往推荐系统里随便输几个用户名，列表普遍缺老动画（少见 2010 前的作品）。请求研究原因。本 ADR 记录调查方法与结论，避免日后重复调查。

调查环境：本地 `data/collections.db`（20k 用户语料，23,941 条目）+ 真实产品 `Recommender`/`score_items` 管道，采样 200-300 评估用户（时间留出切分，重用户），跑多轮后台诊断（年代分布 / 去热惩罚 / 按口味分组对照）。

## 数据发现（均已实测）

### 1. 推荐正确匹配用户口味，老动画不稀缺（按用户已看年代分组，300 用户）

| 用户组（已看老动画占比） | 推荐 top50 老动画占比 |
|---|---|
| 老口味（≥50% 是 2010 前） | **70.3%** |
| 中口味（20-50%） | 38.5% |
| 新口味（<20%） | 8.5% |

- 老口味用户拿到 7 成老动画——**CF 未损坏，推荐忠实反映口味**。
- 300 用户中 **47% 属于"新口味"**（已看老动画 <20%）。随机输用户名大概率碰到这类用户，列表自然偏新。

### 2. 刚上线的 idf_in_score=0 与老动画占比无关

base vs noA 对照：老口味 70.3%→69.9%、中 38.5%→39.4%、新 8.5%→8.0%（全部 <1pp）。"缺老"不是 2026-08-13 的 idf 改动造成的。

### 3. 候选池按收藏数（fav_done）排名天然偏新

- 全语料 31.3% 是 2010 前动画；rank≤3000 池仅 **20.1%**（604/3000 部）。
- **1965-1974 近乎真空**：池内 60 年代仅 2 部（铁臂阿童木 1963、猫和老鼠 1965），1970-74 为 0——全语料有几百部，但收藏数不够进前 3000。
- 这是"能推的老动画上限"：任何配置下推荐里老动画 ≤ 池内占比。

### 4. 池内老经典不缺（可推对象充足）

2000 年前在池内 130 部：EVA(rank5)、星际牛仔(120)、灌篮高手(399)、攻壳机动队(228)、银河英雄传说、机动战士高达 Z、浪客剑心追忆篇(8.9 分)、阿基拉、玲音……都在可推范围。

### 5. "列表看不到老经典"的主因是已看排除

EVA/灌篮这类经典多数用户早已看过 → 被"排除已看"移出个人列表。**列表里看不到 EVA 恰恰因为你看过 EVA**。franchise 排除进一步移走整个系列（看过任一部 → 全系列不进候选）。

### 6. 冷启动/轻量用户（<5 条评分）回退纯流行度

`min_profile=5`，口味信号不足时返回 `log_pop`（热门排序）→ 池内老动画仅 20%，轻量用户列表更显新。

## 结论

"随机用户名缺老动画" = **大多数用户收藏本来就以近年动画为主（推荐忠实反映）** + **池子按收藏数排名偏新（老动画上限 ~20%）** + **已看排除拿掉已看过的经典** + **轻量用户走流行度兜底**。没有单一故障点，无需修改。

## 后续可选方案（用户选定：先不改）

- **A. 池子年代重排**：`fav_done` 按年代衰减（如除以年龄或 log 衰减）重排 rank，让有历史分量的老动画更容易进池。风险：整体面貌变化较大，需重新联调去热/热门占比。
- **B. 老动画配额**：推荐保底 N 条来自老动画池（仿已下线冷门配额 `quota_rank`，不动 CF 排序、Recall 零损失）。改 `src/recommender.py` recommend() + 新构造参数。
- **C. 记档**（本 ADR）。

若日后做 B，验证沿用 `proto_no_idf.py` 思路：对 300 评估用户跑 recommend()，检查老动画（date<2010）占比提升、NDCG/Recall 无回退。
