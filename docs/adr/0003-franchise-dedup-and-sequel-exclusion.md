# ADR 0003：franchise 去重 + 排除已看续作（同一部动画不同季不重复占位）

日期：2026-08-07

## 背景

用户实测发现两个问题：**①已看动画的续作反复出现在推荐里；②同一部动画的不同季/剧场版同时占位**。离线量化（200 重度用户）：纯 CF top-20 里平均 **5.1 条**是已看动画的续作/同季条目。对"发现"定位，续作不是发现——是废话冗余。

## 决策

用 Archive `subject-relations.jsonlines` 建 **franchise 分组**（同一部动画的不同季/续作/剧场版/番外）：

- **关系类型** `type ∈ {2 续作, 3 前传, 6 系列}`（含剧场版/番外）。20k 语料验证：type 4（不同世界观/跨界）与 99（其他）含跨界边，会错误合并 鲁邦三世×柯南 这类 crossover，**排除**；
- **union-find 连通分量**，每个 franchise 以最小 subject_id 为根（稳定可复现）；孤立条目以自身为根；
- 推荐时（`Recommender.recommend`）：
  1. **排除已看 franchise**：用户"看过且评分"的条目所属 franchise 的其余成员，一律不进候选（续作不占位）；
  2. **列表去重**：每个 franchise 只保留 CF 分最高的一条（剧场版/多季不重复占位）；
  3. 以上都在配额（ADR 0002）之前作用于候选集，配额保证的 8 条冷门不受影响。

## 证据（scripts/evaluate_product.py --users 500，20k 语料，SEED=42 可复现）

| 方法 | Recall@10 | NDCG@10 |
|---|---|---|
| 纯 CF | 0.0517 | 0.2252 |
| + franchise 排除/去重 | 0.0447 | 0.2034 |
| + franchise + 配额 8 | 0.0447 | 0.2035 |

- **Recall −13.6% 全部来自 franchise 排除**（fr 与 product 相同，配额追加代价为 0）。500 用户 test 集平均 **15.4 条/用户**是被排除的续作/同季命中——这正是用户要求清除的对象，是"拒绝推续作"的直接代价，不是质量损失；
- **NDCG −9.6%** 同源：S2 这类续作原本常是测试集命中（用户看完 S1 后来看 S2），现在被刻意赶出列表。与 ADR 0002 一致——NDCG 追热不再是目标；
- **修正记录**：早先 200 用户小样本测得"Recall 零损失"是抽样偏差（小样本恰好少含续作命中），本表为大样本可复现结论。
- **稳健性确认**（2026-08-07）：1000 用户复测结果几乎一致——Recall −13.5% / NDCG −9.6%，被排除续作命中 15.9/用户，冷门占比 40.3%、0 重复。结论跨样本稳健。

## 后果

- 新增 `subject_relations` 表（`scripts/import_relations.py`，幂等，29,296 条动画-动画关系，全部类型入库供将来复用）；
- `Recommender` 加载时构建 `_fr`（物品索引对齐的 franchise 根数组）与 `_franchise_root`；`/v1/health` 暴露 `franchise_groups` / `franchise_multi`；
- 大型 franchise（如名侦探柯南 62 成员、宝可梦 66）整体排除——用户看其一即整组不推，符合"不要同一部动画"的明确要求。
