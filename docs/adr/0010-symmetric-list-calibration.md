# ADR 0010：对称列表年代校准

状态：线上启用，强度 0.50（2026-11-03）

## 决策

保留现有协同过滤、作品共现补分和候选过滤。在合法候选中先取 CF 原始分 Top 500，再按用户档案平均年份相对 2014 年中心的偏移，给中心另一侧的作品一个对称的小幅重排补分；最后返回请求的前 k 条。校准不改变候选池，也不改变 API 返回的原始模型分。

重排项为：

```text
adjusted = model_score
         + beta * p90(abs(top500 model_score))
         * (-(user_mean_year - 2014) * (item_year - 2014) / 15^2)
```

`beta=0` 可关闭；线上采用已在独立确认集验证的 `beta=0.50`，中心年为 2014。

## 验证证据

独立 400 用户确认集（每名用户 3 个 80/20 评分留出拆分）中，2000s 与 2020s 用户组的推荐年份差从 22.89 年降到 16.66 年。两端组准确率出现小幅下降，因此保留两个环境开关便于回滚和调参。该评估是已评分作品重建，不代表对用户未看作品的真实点击/观看预测。

详细分组数据与置信区间见 `experiments/user-year-gap-study-20261103.md`。

## 回滚

在服务器 `/opt/bgmlikes/.env` 将 `SLATE_CALIBRATION_BETA` 改为 `0` 并重启 `bgmlikes`；无需重训语料或修改数据库。
